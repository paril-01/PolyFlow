# ADR-0019: Use content-based routing in gateway

## Status
Accepted

## Context
Routes requests based on content type.

## Decision
We will use content-based routing in gateway.

## Category
Architecture

## Author
Frank Johnson (frank.johnson@ecp.dev)

## Date
2024-11-04

## Consequences
- Positive: Improves architecture capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
