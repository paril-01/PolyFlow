# ADR-0017: Use connection pooling for databases

## Status
Accepted

## Context
Reduces connection overhead.

## Decision
We will use connection pooling for databases.

## Category
Performance

## Author
Carol Williams (carol.williams@ecp.dev)

## Date
2024-09-02

## Consequences
- Positive: Improves performance capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
