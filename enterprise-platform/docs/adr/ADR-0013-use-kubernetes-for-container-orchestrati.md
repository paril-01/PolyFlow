# ADR-0013: Use Kubernetes for container orchestration

## Status
Accepted

## Context
Industry standard for container management.

## Decision
We will use kubernetes for container orchestration.

## Category
Infrastructure

## Author
Karen Singh (karen.singh@ecp.dev)

## Date
2024-08-03

## Consequences
- Positive: Improves infrastructure capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
