# ADR-0009: Use feature flags for gradual rollouts

## Status
Accepted

## Context
Reduces risk of big-bang deployments.

## Decision
We will use feature flags for gradual rollouts.

## Category
Process

## Author
Hassan Ali (hassan.ali@ecp.dev)

## Date
2024-07-14

## Consequences
- Positive: Improves process capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
