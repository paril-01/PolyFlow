# ADR-0004: Adopt event-driven architecture for notifications

## Status
Accepted

## Context
Decouples notification from core flows.

## Decision
We will adopt event-driven architecture for notifications.

## Category
Architecture

## Author
Bob Martinez (bob.martinez@ecp.dev)

## Date
2024-12-04

## Consequences
- Positive: Improves architecture capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
