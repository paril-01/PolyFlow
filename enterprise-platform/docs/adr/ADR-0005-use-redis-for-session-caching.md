# ADR-0005: Use Redis for session caching

## Status
Accepted

## Context
In-memory caching reduces DB load by 80%.

## Decision
We will use redis for session caching.

## Category
Performance

## Author
Karen Singh (karen.singh@ecp.dev)

## Date
2024-11-25

## Consequences
- Positive: Improves performance capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
