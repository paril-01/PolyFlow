# ADR-0007: Use Terraform for infrastructure

## Status
Accepted

## Context
Infrastructure as code enables reproducibility.

## Decision
We will use terraform for infrastructure.

## Category
DevOps

## Author
David Kim (david.kim@ecp.dev)

## Date
2024-07-15

## Consequences
- Positive: Improves devops capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
