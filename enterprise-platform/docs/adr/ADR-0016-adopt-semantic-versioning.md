# ADR-0016: Adopt semantic versioning

## Status
Accepted

## Context
Clear versioning communicates breaking changes.

## Decision
We will adopt semantic versioning.

## Category
Process

## Author
Leo Rivera (leo.rivera@ecp.dev)

## Date
2024-06-26

## Consequences
- Positive: Improves process capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
