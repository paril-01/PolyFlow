# ADR-0003: Use JWT for authentication tokens

## Status
Accepted

## Context
Stateless auth enables horizontal scaling.

## Decision
We will use jwt for authentication tokens.

## Category
Security

## Author
Iris Nakamura (iris.nakamura@ecp.dev)

## Date
2024-10-14

## Consequences
- Positive: Improves security capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
