# ADR-0002: Adopt gRPC for inter-service communication

## Status
Accepted

## Context
REST has too much overhead for internal calls.

## Decision
We will adopt grpc for inter-service communication.

## Category
Communication

## Author
Iris Nakamura (iris.nakamura@ecp.dev)

## Date
2024-05-15

## Consequences
- Positive: Improves communication capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
