# ADR-0001: Use PostgreSQL as primary datastore

## Status
Accepted

## Context
We need ACID compliance and JSON support.

## Decision
We will use postgresql as primary datastore.

## Category
Database

## Author
Frank Johnson (frank.johnson@ecp.dev)

## Date
2024-07-20

## Consequences
- Positive: Improves database capabilities
- Negative: Adds operational complexity
- Risks: Team needs training on new technology
