# 🕸️ Knowledge Graph

The engineering knowledge graph represents the relationships between all engineering artifacts in a project.

## Purpose

The knowledge graph enables any agent to quickly understand:
- How modules relate to each other
- What depends on what
- Who owns what
- What decisions led to the current state
- What risks exist
