# 💡 Example Projects

These examples demonstrate the AI Engineering Framework in action across complete project lifecycles.

| Example | Type | Description |
|---------|------|-------------|
| [Web API Project](web-api-project/) | REST API | Building a team task management API from discovery through release |
| [CLI Tool Project](cli-tool-project/) | CLI Application | Building a code quality analysis CLI tool from idea to release |

Each example walks through all 5 phases:
1. **Discovery** — Maker Agent discovers requirements
2. **Architecture** — Maker Agent designs the architecture
3. **Implementation** — Implementer Agent builds the code
4. **Review** — Reviewer Agent reviews the work
5. **Release** — Gatekeeper Agent makes the release decision
