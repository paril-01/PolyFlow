# Code Review Protocol

## Trigger
Code is ready for review (after self-review by the author).

## Process
1. **Read the change description** — understand what and why
2. **Review the diff** — every changed line
3. **Check each review dimension** (see [Review Dimensions](../agents/reviewer/review-dimensions.md))
4. **Classify findings** using the [Severity Matrix](../agents/reviewer/severity-matrix.md)
5. **Provide actionable feedback** — specific suggestions, not vague complaints
6. **Acknowledge good work** — positive feedback matters
7. **Issue verdict** — Approve, Conditional, Request Changes, or Reject

## Guidelines
- Complete reviews within 24 hours of submission
- Keep comments constructive and professional
- Distinguish must-fix (P0-P1) from suggestions (P3-P4)
- If you can't review a particular dimension, say so
