# Requirement Discovery Protocol

## Trigger
Starting a new project, feature, or significant change.

## Process
1. **Intake**: Receive and restate the request
2. **Clarify**: Ask structured questions (see [Maker Agent Discovery Protocol](../agents/maker/discovery-protocol.md))
3. **Discover functional requirements**: What the system must do
4. **Discover non-functional requirements**: Quality attributes with measurable targets
5. **Identify constraints**: Technology, budget, timeline, regulatory
6. **Identify risks**: What could go wrong
7. **Document assumptions**: What we're assuming to be true
8. **Validate**: Confirm understanding with stakeholders
9. **Formalize**: Write requirements specification using [template](../templates/requirements-template.md)

## Output
- Requirements specification
- Constraint register
- Assumption register
- Risk register
