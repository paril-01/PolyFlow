# Documentation Standards

See [Constitution — Documentation Standards](../constitution/documentation-standards.md) for the foundational documentation principles.

## Summary
- Document the **what**, **why**, **how**, **when**, and **who**
- Document **before** implementation (design), **during** (code comments), and **after** (deployment guides)
- Keep docs **close to the code**
- Update docs as part of every change
- Use **templates** for consistency
