# Assumption Register Template

```markdown
# Assumption Register — [Project Name]

| ID | Assumption | Category | Impact if Wrong | Validation Method | Status |
|----|-----------|----------|-----------------|-------------------|--------|
| A-01 | [Assumption description] | Technical/Business/User | [What breaks if wrong] | [How to verify] | Unvalidated/Validated/Invalidated |
| A-02 | [Assumption description] | Technical/Business/User | [What breaks if wrong] | [How to verify] | Unvalidated/Validated/Invalidated |
```

## Usage
1. Record every assumption made during design and implementation
2. Assign a validation method — how will you confirm the assumption?
3. Validate assumptions as early as possible
4. If an assumption is invalidated, reassess the design
