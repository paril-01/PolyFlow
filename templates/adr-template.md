# ADR Template

See [agents/maker/adr-template.md](../agents/maker/adr-template.md) for the complete ADR template with instructions.

## Quick Reference

```markdown
# ADR-[NUMBER]: [TITLE]

## Status
[Proposed | Accepted | Deprecated | Superseded by ADR-XXX]

## Date
[YYYY-MM-DD]

## Context
[What situation requires a decision?]

## Decision Drivers
- [Key factor 1]
- [Key factor 2]

## Considered Options
### Option 1: [Name]
### Option 2: [Name]
### Option 3: [Name]

## Decision
[Which option was selected]

## Rationale
[Why this option was chosen]

## Consequences
### Positive
### Negative
### Risks
```
