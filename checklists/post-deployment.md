# Post-Deployment Checklist

- [ ] Application is running and responding
- [ ] Health check endpoint returns healthy
- [ ] Error rates are at or below baseline
- [ ] Response times are within acceptable range
- [ ] No new errors in logs
- [ ] Key business flows verified manually
- [ ] Database migration applied successfully
- [ ] Monitoring alerts are not firing
- [ ] Status page updated (if applicable)
- [ ] Rollback plan still ready for 24 hours
- [ ] Team notified of successful deployment
