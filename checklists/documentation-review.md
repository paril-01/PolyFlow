# Documentation Review Checklist

- [ ] README is current and accurate
- [ ] API endpoints are documented with examples
- [ ] Configuration options are documented with defaults
- [ ] Architecture decisions are recorded as ADRs
- [ ] Deployment procedure is documented
- [ ] Environment setup instructions work
- [ ] Inline code comments explain "why" for non-obvious logic
- [ ] CHANGELOG is updated for this release
- [ ] Known issues and limitations are documented
- [ ] Error codes and messages are documented
