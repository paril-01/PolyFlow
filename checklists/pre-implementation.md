# Pre-Implementation Checklist

Complete before writing any code.

- [ ] Requirements are documented and understood
- [ ] Design document exists and is approved
- [ ] ADRs exist for significant decisions
- [ ] Scope is clearly defined (in and out)
- [ ] Acceptance criteria are defined
- [ ] Dependencies are identified
- [ ] Impact on existing code is assessed
- [ ] Testing strategy is planned
- [ ] Reviewer Agent has validated the design
- [ ] All open questions are resolved
