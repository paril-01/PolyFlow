# Testing Completeness Checklist

- [ ] Unit tests cover critical business logic
- [ ] Integration tests cover external system interactions
- [ ] Edge cases tested (null, empty, max values, boundary conditions)
- [ ] Error paths tested (what happens when things fail?)
- [ ] Negative tests exist (inputs that should be rejected)
- [ ] Tests are independent (no order dependency)
- [ ] Tests are deterministic (same result every run)
- [ ] Test names describe the scenario
- [ ] Test data is realistic
- [ ] Regression tests exist for previously found bugs
- [ ] All tests pass in CI/CD
- [ ] Coverage meets project standards for critical paths
