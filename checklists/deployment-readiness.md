# Deployment Readiness Checklist

- [ ] All tests pass in CI/CD pipeline
- [ ] Code review approved by Reviewer Agent
- [ ] Gate review approved by Gatekeeper Agent
- [ ] Database migrations tested (including rollback)
- [ ] Configuration changes documented
- [ ] Environment variables set in target environment
- [ ] Rollback plan documented and tested
- [ ] CHANGELOG and version updated
- [ ] Staging deployment successful
- [ ] Staging verification complete
- [ ] On-call team notified
- [ ] Monitoring dashboards ready
- [ ] Not deploying on Friday (or before holiday)
